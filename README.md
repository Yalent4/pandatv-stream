软件简介
--------
Panda LIVE Recorder 是面向 PandaLive 的 Windows 图形化直播录制工具。
程序支持多个 BJ 同时录制、直播间画质检测、逐任务控制、普通浏览器登录，
并在后台调用 N_m3u8DL-RE 保存直播内容。

主要功能
--------
1. 只需填写 PandaLive 播放页中 play/ 后面的 BJ ID。
2. 每个任务独立检测直播间真实存在的数字画质。
3. 检测结果仅显示 480、720、1080 等数字画质。
4. 必须先选择画质，当前行的“录制”按钮才会启用。
5. 支持多个 BJ 同时录制。
6. 每行均有“检测、录制、停止、删除”按钮，互不影响。
7. 支持普通 Chrome、Edge、Brave、Chromium 浏览器登录。
8. 网站确认真正登录成功后，程序自动取得 Cookie 并保存登录状态。
9. N_m3u8DL-RE 和浏览器辅助程序均在后台运行，不弹出命令行窗口。
10. 支持浅色、深色以及蓝色、紫色、青色、橙色主题。
11. 支持代理端口设置
系统要求
--------
- Windows 10 或 Windows 11，64 位系统。
- 建议使用 Chrome 或 Edge 完成需要账号权限的直播间登录。
- 需要能够正常访问 https://www.pandalive.co.kr/ 。

下载与安装
----------
1. 打开项目 GitHub 页面。
2. 进入 Releases。
3. 下载 PandaLIVE_Recorder_1.0.0.zip。
4. 将 ZIP 完整解压到普通文件夹。
5. 双击 PandaLIVE_Recorder_1.0.0.exe。

请不要只把 EXE 单独复制出来。node.exe、N_m3u8DL-RE.exe 和 _internal
文件夹都必须与主程序保持在同一目录。

录制公开直播间
--------------
1. 打开软件左侧“录制”页面。
2. 点击“添加任务”。
3. 在 BJ ID 中填写主播名称，例如播放地址：
   https://www.pandalive.co.kr/play/freezia
   对应 BJ ID 为 freezia。
4. 点击当前行“检测”。
5. 检测成功后，在“画质”中选择需要的数字画质。
6. 点击当前行“录制”。
7. 需要结束时点击当前行“停止”。

录制需要账号权限的直播间
------------------------
1. 打开“设置”页面。
2. 点击“浏览器登录”。
3. 软件会自动寻找本机可用的 Chrome、Edge、Brave 或 Chromium。
4. 在打开的普通浏览器窗口内完成登录、验证码或成人验证。
5. 等待网站显示为真正登录状态。
6. 软件连续确认登录状态后会自动取得 Cookie。
7. 登录成功前没有时间限制；用户也可以直接关闭浏览器取消登录。

仅出现 Cookie、仍停留在密码/验证码页面或网站显示登录失败时，
程序不会把它误判为登录成功。

录像保存位置
------------
默认保存在程序目录旁的 recordings 文件夹，并按日期建立子目录。
可以在“设置”页面选择其他保存目录，也可以在“存储”页面查看最近文件。

常见问题
--------
一、为什么检测后没有自动录制？
这是正常设计。检测只负责读取画质，必须由用户选择画质并点击“录制”。

二、为什么没有 source 或 auto？
界面只保留可以明确选择的数字画质，避免自动源造成录制结果不确定。

三、为什么检测不到画质？
请先确认 BJ ID 正确、主播正在直播，并检查该直播间是否需要登录或房间密码。

四、为什么浏览器不会马上退出？
只有确认网站真正登录成功后才会自动关闭。登录失败、验证码未完成时会继续等待。

五、停止一个任务会影响其他任务吗？
不会。每一行的停止和删除只作用于当前任务。

六、Windows 提示“未知发布者”怎么办？
当前程序没有商业代码签名证书。请确认文件来自本项目 Releases，
核对发布页面提供的 SHA-256 后再选择运行。
